# BergHanziTrainer 0.4.0 — «Ключи и честная проверка»

Собрано с коммита `c524505` (ветка `release-0.4`), versionCode 4.

## Заголовок и подзаголовок

**Учите иероглифы через ключи**
Найдите все слова с 水 и пишите только их. Проверка черт теперь замечает пропущенный крючок.

Запасные варианты заголовка:
- «Одна тема — один ключ — одна тренировка»
- «Теперь приложение видит, что вы не дописали черту»

## Короткое описание (до 300 знаков: Telegram, VK, превью)

BergHanziTrainer 0.4: из «Ключей» открываются все слова с этим ключом, а тренировка идёт только по найденным словам — по ключу или по поиску. Проверка черт стала строже и ловит пропущенный крючок, недописанную черту и зигзаг.

## «Что нового в 0.4.0» (для сайта, в формате блока 0.3.0)

- Тренировка по поиску: найдите в списке слова с 水 — «Письмо», «Тест» и «Пропись» пойдут только по ним
- В «Ключах» у каждого ключа кнопка «Слова с этим ключом»: открывает «Все слова» с этим ключом, и тренироваться можно только по ним
- В карточке слова раздел «Ключи»: ключ каждого иероглифа из словаря, плюс свои ключи через «Добавить ключ»
- Проверка черт строже: не засчитывает пропущенный или лишний крючок, недописанную черту, зигзаг и лишние штрихи
- Подсказка рисуется по тем же чертам, по которым идёт проверка
- 15 форм ключей, которых не хватало (⻌, ⺧, ⺩, 牜, 龵 и другие), теперь пишутся с проверкой; 阝 стоит справа в значении «город» и слева в значении «холм»

>

>
> 🔑 **Слова одного ключа.** В списке «Ключи» нажмите на ключ — откроются все ваши слова с ним. Тренировка пойдёт только по этим словам: например, сегодня все слова «про воду».
>
> 🔍 **Тренировка по поиску.** То же работает с обычным поиском: введите 学 или «школа», и «Письмо», «Тест» и «Пропись» пройдут только по найденным словам.
>
> 🏷 **Ключи в карточке слова.** У каждого слова видны ключи его иероглифов. Можно добавить и свои — например, если запоминаете 爱 через 心, как в старом 愛.

> ✍️ **Проверка строже.** Раньше приложение принимало черту, если она шла в правильную сторону. Теперь оно не засчитает пропущенный крючок у 了, черту, брошенную на середине, или зигзаг. Правильно написанные черты проходят как и раньше.

## Факты для ответов на вопросы

- Пороги новой проверки настроены на 215 чертах, написанных на телефоне. Все правильные черты проходят; из 48 неправильных отклоняются 37 (раньше 13). Это внутренний тест — в публичных текстах лучше говорить «замечает больше ошибок», без процентов, или подавать цифру именно как результат нашего теста.
- Для 靣 и 髙 данных черт по-прежнему нет — они тренируются без проверки.
- Свои ключи слова сохраняются в резервной копии и передаются вместе со словами, когда делитесь списком (JSON списка).
- Обновление ставится поверх 0.3.0, слова и списки сохраняются.

## Что показать на скриншотах / в видео

1. «Ключи» → нажатие на 氵 → «Ключ 85 · вода» со списком слов → старт тренировки.
2. Поиск 学 в «Все слова» → тренировка идёт только по найденным словам.
3. Карточка слова с разделом «Ключи»: библиотечный ключ и добавленный вручную.
4. Короткое видео: пишем 了 без крючка — черта не засчитана; с крючком — засчитана.
