## Короткое описание (до 300 знаков: Telegram, VK, превью)

BergHanziTrainer — бесплатный тренажёр китайских иероглифов для Android. Показывает порядок черт, проверяет каждую черту,
ведёт от обводки к письму по памяти. Свои списки слов, импорт из Pleco и Anki, тест с подсчётом ошибок. Работает без
интернета.

## Пост для соцсетей / Telegram-канала

> **BergHanziTrainer 0.3 — тренажёр написания иероглифов**
>
> Читать 我 и уметь его написать — разные навыки. Это приложение тренирует второй: вы пишете иероглиф пальцем, а оно
> проверяет каждую черту — направление, порядок, место в клетке.
>
> 描 **Пропись.** Новый иероглиф проходит пять шагов: приложение показывает порядок черт → вы обводите с подсказкой →
> обводите без неё → пишете, видя только следующую черту → пишете по памяти. В конце слово пишется целиком.
>
> 字 **Письмо.** Видите перевод и пиньинь — пишете иероглифы сами. Забыли — кнопка «Подсказка» покажет контур.
>
> 🔤 **Пиньинь.** Включите переключатель — чтение скроется, его нужно будет ввести. Тон цифрой или кнопкой: nv3 → nǚ.
> Приложение отдельно скажет, если ошибка только в тоне.
>
> 📝 **Тест.** Без подсказок, слова вперемешку, ошибки считаются. 5, 10 или все слова списка — в конце видно, какие
> слова написаны чисто, а где были ошибки.
>
> 📚 **Свои списки.** Сразу есть 6 стартовых списков (местоимения, глаголы, семья, места, еда…) и справочник «Ключи» —
> 214 ключей Канси. Добавляйте свои слова и списки, одно слово может быть в нескольких списках.
>
> 🔁 **Импорт и экспорт.** Слова из Pleco, Anki или Excel переносятся файлом или вставкой текста. Список можно выгрузить
> для Pleco, отправить другу файлом JSON или сохранить резервную копию всех слов и списков.
>
> Бесплатно, без рекламы, без интернета. Android 10+, 9 574 иероглифа с порядком черт.

## Факты для ответов на вопросы

- Данные о порядке черт — из открытого проекта Make Me a Hanzi (9 574 иероглифа). Для иероглифов без данных в прописи
  показывается «Нет написания», слово тренируется без проверки этого знака.
- Приложение не запрашивает доступ к сети: слова и списки хранятся только на телефоне.
- Импорт ничего не удаляет. Каждое слово сверяется со списком «Все слова»: новые добавляются, совпавшие не дублируются,
  слова с другим чтением приложение просит уточнить. Файлы до 5 МБ, в кодировке UTF-8.
- JSON списка — выбранные списки с их словами, для другого телефона. Резервная копия — все слова и списки сразу.
- Удаление списка не удаляет слова: они остаются в «Все слова». Удаление слова убирает его из всех списков.
- Пиньинь проверяется без учёта пробелов между слогами (nǐhǎo и nǐ hǎo — одно и то же).
- Версии для iPhone нет. Распространяется APK с сайта, Google Play — в планах.

## Что показать на скриншотах / в видео

1. Пропись 我: показ порядка черт с лентой шагов → обводка → по памяти.
2. Ошибка в обводке: приложение подсвечивает, как провести черту.
3. «Письмо» с включённым «Пиньинь»: иероглифы, затем ввод nv3 → nǚ.
4. Итог теста: число слов, ошибок и список слов с ошибками.
5. Экран «Списки»: стартовые списки, «Ключи», «Все слова».
6. Импорт: вставка строки `你好	ni3 hao3	привет` → проверка импорта «Новых: 1».
