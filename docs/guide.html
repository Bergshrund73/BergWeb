Как пользоваться BergHanziTrainer

Всё об основных функциях приложения: списки и слова, режимы тренировки, импорт и экспорт. Описана версия 0.4.0.

Первый запуск

После установки сразу открывается экран «Списки». На нём уже есть:

  • 6 стартовых списков — местоимения, глаголы, прилагательные, семья и люди, места, еда и напитки (60 слов);
  • «Все слова» — общий список: в него попадает каждое слово из любого вашего списка;
  • «Ключи» — справочник 214 ключей Канси с вариантами форм (⺮, 亻, 氵…).

Списки, которые вы создаёте, идут сверху, новые — первыми. Чтобы найти список по названию, воспользуйтесь поиском.

Приложению не нужен интернет: всё хранится на телефоне.

Списки и слова

Создать список — кнопка «Создать список», затем название. В меню списка («Ещё») его можно переименовать, удалить или выгрузить. При удалении списка слова не теряются — они остаются в «Все слова».

Найти слово — поиск в списке ищет по переводу, иероглифам и пиньиню.

Добавить слово — если поиск ничего не нашёл, появится «Добавить новое слово». В карточке слова три поля: иероглифы, пиньинь, перевод. Ниже — списки, в которые попадёт слово: можно выбрать сразу несколько или создать новый прямо отсюда. «Все слова» слово получает всегда.

Изменить или удалить слово — откройте его в списке. Поменять можно и текст, и списки. Удаление убирает слово из всех списков вместе с прогрессом по нему.

Тренировка

Откройте список и нажмите кнопку настроек над словами. Выберите режим и переключатели — приложение запомнит выбор.

Пропись — чтобы выучить новый иероглиф

Каждый иероглиф слова проходит раунды, и подсказок с каждым раундом меньше:

  1. Показ порядка черт — иероглиф рисуется по одной черте, рядом лента со всеми шагами. Тап по клетке пропускает показ.
  2. Обводка с подсказкой — обводите контур. Ошиблись — приложение покажет, как провести черту.
  3. Обводка — контур тот же, подсказка только после ошибки.
  4. Частичная опора — видна лишь следующая черта.
  5. По памяти — пустая клетка с сеткой 田.

Если в слове несколько иероглифов, в конце оно пишется целиком. Пройденный иероглиф можно написать ещё раз.

Если для иероглифа нет данных о чертах, вместо прописи будет «Нет написания».

Письмо — чтобы проверить себя

Видны перевод и пиньинь, иероглифы вы пишете сами. Забыли — «Подсказка» покажет контур, «Скрыть» уберёт его.

Переключатель «Пиньинь»

Работает в обоих режимах. Чтение скрыто — после иероглифов его нужно ввести. Тон ставится цифрой после слога или кнопкой: nv3 → nǚ, hao3 → hǎo. Пробелы между слогами не важны. Если ошибка только в тоне, приложение так и скажет — «Неверный тон» — и покажет правильный ответ.

Переключатель «Тест»

Без подсказок, слова вперемешку, ошибки считаются. Выберите, сколько слов проверить: 5, 10 или все. В конце — итог: сколько слов, сколько ошибок и какие слова написаны с ошибками. Тест проходится и без пиньиня.

Кнопки под клеткой

  • Отменить — убрать последнюю черту;
  • Стереть — очистить клетку;
  • Заново — начать слово с первого иероглифа;
  • Подсказка — показать контур.

Пишите черты в правильном порядке и направлении: каждая проверяется сразу. Не засчитываются пропущенный крючок, недописанная черта и зигзаг.

Тренировка по части списка

Введите что-нибудь в поиск списка — тренировка пойдёт только по найденным словам. В «Ключах» у каждого ключа есть «Слова с этим ключом»: так можно тренировать, например, все слова с 氵.

Импорт слов

Экран «Импорт / экспорт», вкладка «Копия и импорт».

Что можно загрузить:

  • файлы .txt, .csv, .tsv — выгрузки из Pleco, Anki, таблицы Excel;
  • JSON со списками из BergHanziTrainer;
  • резервную копию;
  • текст, вставленный прямо в поле, — например 你好 ni3 hao3 привет (через табуляцию).

Как идёт импорт:

  1. Для текстового файла укажите разделитель (табуляция, точка с запятой, запятая), есть ли строка заголовка и какая колонка за что отвечает: иероглифы, пиньинь, перевод или «Пропустить».
  2. Выберите, куда добавить слова: в новый список, в существующий или только в «Все слова».
  3. Приложение покажет проверку: сколько слов новых, сколько уже есть, сколько повторяются в файле и где ошибки. Если у слова в файле другое чтение, чем в «Все слова», его нужно уточнить или пропустить.
  4. Если перевод в файле отличается, можно заменить старые переводы новыми.

Импорт ничего не удаляет и не создаёт дубли. Файл — до 5 МБ, в кодировке UTF-8. Строки с ошибками можно скачать отчётом.

Экспорт и резервная копия

Экспорт списка — вкладка «Экспорт списков» или меню списка:

  • TXT для Pleco — чтобы учить те же слова в Pleco;
  • JSON — скачать или сразу отправить через мессенджер. Подходит для другого телефона с BergHanziTrainer: слова и списки без прогресса.

Резервная копия — все слова, списки и прогресс одним JSON-файлом. Приложение показывает, когда копия выгружалась в последний раз. Чтобы восстановить, загрузите файл через импорт.

Обновление

Новая версия ставится поверх старой: скачайте APK и установите — слова, списки и прогресс сохранятся. Перед обновлением на всякий случай сохраните резервную копию.
